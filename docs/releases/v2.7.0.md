## ⪩ Media Saver v2.7.0 ⪨

The app now looks for a new version every 5 minutes, and the check interval setting is gone.

---

### ⤷ Changed ˎˊ˗

- **Update check** — while the app runs it looks for a new version every 5 minutes (before: every 30 minutes by
  default). A failed check is retried later with a growing wait of up to an hour, and nothing is checked without a
  network connection. With **Download updates automatically** on (the default) a new version is fetched in the
  background; installing it still needs **Restart to update**.

### ⤷ Removed ˎˊ˗

- **Check interval** — the setting is removed from Settings > Updates, which now has the status row and the
  **Download updates automatically** switch. The value stored by earlier versions is ignored.
