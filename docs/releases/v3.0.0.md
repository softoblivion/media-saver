## ⪩ Media Saver v3.0.0 ⪨

A new look: four colour themes, a darker background, one button style everywhere and smoother motion.

---

### ⤷ Added ˎˊ˗

- **Theme** — Settings > Appearance offers four themes: **Dusk** (the default), **Nova**, **Frost** and **Bloom**.
  A theme sets the background colour and the accent of the window; the choice is saved and the app starts with it.

### ⤷ Changed ˎˊ˗

- **Background** — the window is darker, with soft colour fields in the hue of the theme and a small accent glow;
  the old blue-violet background is gone.
- **Buttons** — every button has the same raised plate with a light rim; the **Download** button is a glass pill
  that takes the accent colour of the theme while links are ready, shows the download level while the batch runs
  and turns green when it is done.
- **Motion** — queue items enter and leave with the same movement as the rest of the window, and menus, chevrons
  and state changes use one set of timings.
