## ⪩ Media Saver v2.1.0 ⪨

This release gives the download engine the JavaScript runtime that YouTube extraction now requires, so every
machine downloads the full format list without warnings.

---

### ⤷ Added ˎˊ˗

- **Deno runtime for YouTube** — the engine updater installs [Deno](https://deno.com/) next to yt-dlp, gallery-dl
  and FFmpeg: the official Windows x64 release is downloaded once (about 41 MB), verified by SHA-256 against the
  published checksums (the archive and the extracted executable), and refreshed at most every 30 days. A copy
  already on `PATH` is used instead. yt-dlp receives the bundled runtime explicitly, so the "no supported
  JavaScript runtime" warning is gone and YouTube serves every format it has.
- **Deno in the engine panel** — the engine popover and the Settings versions block show the runtime with its
  version and whether it is bundled or taken from the system.

### ⤷ Changed ˎˊ˗

- **Stereo first** — YouTube now also offers 5.1 surround tracks (AAC, AC-3, E-AC-3); the format choice prefers a
  stereo or mono track over surround, so MP4 files keep a plain stereo track and MP3 is made from the stereo source.
- The first start now downloads about 80 MB of engines (yt-dlp, gallery-dl and Deno) instead of about 40 MB;
  FFmpeg is still fetched only when the machine has none.
- Deno's cache lives in `media-saver_data\cache\deno`, so the portable data folder keeps holding everything the app
  writes.

### ⤷ Fixed ˎˊ˗

- YouTube downloads on machines without a JavaScript runtime no longer depend on yt-dlp's deprecated extraction
  path, which was due to lose formats or get throttled when YouTube changes its player.

### ⤷ Removed ˎˊ˗

- Nothing.
