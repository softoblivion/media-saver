## ⪩ Media Saver v2.1.1 ⪨

A fix for the in-app update: installing a new version no longer opens console windows or hangs.

> Copies of 2.0.0 and 2.1.0 cannot update themselves (the bug is in their own updater). Download this `MediaSaver.exe` once by hand and put it in place of the old one; from now on **Restart to update** works.

---

### ⤷ Added ˎˊ˗

- `media-saver_data\updates\apply.log` records every step of an update (wait, swap, restart), so a failed update can be explained.

### ⤷ Changed ˎˊ˗

- **How an update is installed** — the downloaded `MediaSaver.exe` now swaps itself in: it waits for the running app to exit, keeps the old file as `MediaSaver.exe.old`, copies itself over the installed exe and restarts the app. No script and no console are involved any more.

### ⤷ Fixed ˎˊ˗

- **Restart to update hung** — the previous updater ran a command script without a console, which made every command it used open a visible console window and wait for keyboard input; the update never completed.

### ⤷ Removed ˎˊ˗

- The `apply-update.cmd` helper script; a leftover from an earlier version is deleted on the next launch.
