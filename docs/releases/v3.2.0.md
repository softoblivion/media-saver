## ⪩ Media Saver v3.2.0 ⪨

One compact design shared with the other apps: a new typeface, a tighter layout, the same title bar everywhere
and a Scale setting for the whole window.

---

### ⤷ Added ˎˊ˗

- **Scale** — Settings > Appearance > **Scale** sets the size of the whole window and its text: 100, 125, 150,
  175 or 200 % on top of the Windows display scaling. The window grows with the step and takes effect at once; on
  a small screen it keeps a layout step that still fits.

### ⤷ Changed ˎˊ˗

- **Typeface** — the window is set in Sora with one fixed scale of text sizes; headings, labels, buttons and
  meta lines are each one size, so the same thing looks the same everywhere.
- **Compact layout** — smaller buttons, switches, segmented controls, fields, rows and cards; a 44 px title bar;
  the Download pill and the MP4 / MP3 toggle are 48 px.
- **Title bar** — the settings button sits with Minimize and Close in one glass cluster on the right; the engine
  status chip stays left of it; the source selector stays in the centre of the window.
