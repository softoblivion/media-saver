## ⪩ Media Saver v2.3.1 ⪨

Internal rework of the update mechanism; the app looks and behaves as in 2.3.0.

---

### ⤷ Changed ˎˊ˗

- **Update mechanism as its own package** — checking, downloading, verifying and installing app updates now live
  in a self-contained package inside the app (`app/vendor/selfupdate`). Messages, files in
  `media-saver_data\updates` and the **Restart** flow are unchanged.
- The update source can be pointed at a local server with the `MEDIA_SAVER_RELEASE_URL` environment variable, for
  testing an update end to end before a release. Without the variable the app checks GitHub as before.
