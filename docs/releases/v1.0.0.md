## ⪩ Media Saver v1.0.0 ⪨

---

### ⤷ Added ˎˊ˗

- **Maximum-quality downloads** — format selection by resolution, then frame rate, then bitrate across DASH and progressive streams; video and audio merged into MP4.
- **H.264 compatibility mode** — AVC stream preferred at the top resolution; VP9 / AV1 sources re-encoded with x264 CRF 16 and AAC audio for Premiere Pro and After Effects.
- **Quality caps** — `1080` and `720` modes limit the short side of the video.
- **Batch link input** — extraction of any number of links from free text, glued URLs, Markdown links and `.txt` files; drag and drop and window-wide `Ctrl+V`.
- **Link cleaner** — canonical `https://www.instagram.com/reel/<shortcode>` output with tracking parameters and path tails removed; `/reels/`, `/tv/` and `/<user>/reel/` mapped to `/reel/`; `l.instagram.com` redirect unwrapping; duplicate and invalid link counters.
- **Download queue** — 1–4 parallel jobs with per-job progress, speed, ETA, thumbnails, cancel, retry, open and reveal actions; history of the last 300 jobs kept across restarts.
- **Engine auto-update on launch** — checksum-verified updates of `yt-dlp` (nightly or stable channel), `gallery-dl` and FFmpeg; offline mode with the binaries already present.
- **Self-healing retries** — one forced engine update and automatic retry after an extractor failure; back-off retries after rate limiting.
- **Authentication fallback chain** — anonymous request, saved session, optional browser cookies, then `gallery-dl`.
- **In-app Instagram sign-in** — Instagram's own login page in a separate window; session cookies stored locally, password never handled by the app; `cookies.txt` import and sign-out.
- **Clipboard prompt** — links found in the clipboard offered for download when the window gains focus.
- **Skip existing files** — jobs whose target file already exists finish instantly as already downloaded.
- **File name templates** — `{author}`, `{shortcode}`, `{date}` and `{title}` tokens with Windows-safe sanitising.
- **Liquid Glass interface** — SVG displacement refraction, specular highlights, spring-driven morphing controls, settings sheet, engine status popover and toasts; reduced-motion support.
- **Frameless window** — Windows 11 rounded corners, edge resizing, maximize to the work area, single-instance guard.
- **Portable executable** — one-file `MediaSaver.exe` with no installer and no admin rights; runtime data in `%LOCALAPPDATA%\MediaSaver`.
- **Developer tooling** — headless CLI, simulated engine (`--fake`), browser mock of the bridge API, unit test suite and a one-command PowerShell build.
