## ⪩ Media Saver v2.2.0 ⪨

Two more platforms: TikTok videos and X (Twitter) posts download next to Instagram Reels and YouTube videos, with the same batch input, previews, MP4 / MP3 output and per-platform quality.

---

### ⤷ Added ˎˊ˗

- **TikTok mode** — paste full links (`tiktok.com/@user/video/<id>`) or the short share links the app hands out (`vm.tiktok.com/<code>`, `vt.tiktok.com/<code>`, `tiktok.com/t/<code>`). The watermarked copy TikTok offers is never picked; the best clean file is (1080p HEVC on current videos, which the H.264 pass converts for editors when that switch is on). Quality: Low (≤ 480p), Medium (≤ 720p), Max. Photo posts, profiles, LIVE and sounds are reported as unsupported.
- **X mode** — paste post links (`x.com/<user>/status/<id>`, `twitter.com/...`, `/i/web/status/...`); tails such as `?s=20&t=`, `/video/1` and `/photo/1` are stripped. The progressive MP4 of the post is downloaded in one piece (no HLS fragments). Quality: Low, Medium, Max (up to 1080p). Profiles, Spaces, broadcasts and `t.co` short links (which need the browser to resolve them) are reported as unsupported.
- **Mode switch with four entries** in the title bar: Instagram, YouTube, TikTok, X (`Alt+1` … `Alt+4`); each mode keeps its own queue view, quality setting and clipboard offers.
- **Browser cookies for TikTok and X** — age-restricted and sensitive posts that the sites show to signed-in users only use the browser chosen in Settings, as YouTube already did.
- Settings keys `quality_tiktok` and `quality_twitter` (`low` | `medium` | `max`, default `max`); `mode` accepts `tiktok` and `twitter`.

### ⤷ Changed ˎˊ˗

- Error messages of a job name only its own site (TikTok and X texts for blocked, private, deleted and sign-in cases); the "About" line and the README describe four platforms.
- A video format whose codecs the site does not announce (X's progressive files) is treated as a muxed H.264 file: no second audio track is added and the H.264 pass runs only when the downloaded file turns out not to be AVC.
