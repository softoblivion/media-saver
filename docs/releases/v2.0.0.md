## ⪩ Media Saver v2.0.0 ⪨

Reels Saver is now **Media Saver**. This release renames the app, moves its data next to the executable, adds
YouTube and MP3, previews queued links and lets the app update itself. Two changes are breaking for existing users,
see **Changed**.

---

### ⤷ Added ˎˊ˗

- **YouTube videos and Shorts** next to Instagram Reels. An Instagram / YouTube mode switch in the window; each mode
  keeps its own queue view, both are saved across restarts.
- **YouTube link cleaner** — `youtu.be/<id>`, `watch?v=`, `/shorts/`, `/embed/`, `/live/`, mobile and Music
  hosts are extracted from any text and reduced to `https://www.youtube.com/watch?v=<id>` or
  `https://www.youtube.com/shorts/<id>`; timestamps, playlist and tracking parameters are dropped. A link of the
  other platform is shown with a one-click **Switch** action.
- **MP3 output** — a global MP4 / MP3 toggle plus a per-item override on queued cards. Audio is extracted at the
  best available bitrate; FFmpeg is fetched automatically when the machine has none.
- **Previews in the queue** — thumbnail, title, author and duration appear on a card right after the link is
  queued, before the download starts; the download reuses the fetched metadata.
- **Self-update from GitHub Releases** — a check on launch (switchable in Settings) and a **Check for updates**
  button; the new `MediaSaver.exe` is downloaded into the data folder, verified by size and SHA-256 against the
  published `SHA256SUMS`, and swapped in on restart by a small helper. The current version is shown in the window.
- **Embedded fonts** — Inter and Geist Mono ship inside the app (SIL Open Font License); nothing is loaded from
  the network.
- **Quality per platform** — Instagram Low / Medium / Max and YouTube 360p / 720p / Max, chosen in the main
  window next to the mode and format controls instead of the settings sheet.
- Settings: `mode`, `format`, `quality_instagram`, `quality_youtube`, `check_app_updates`. Headless CLI:
  `--platform`, `--format`.

### ⤷ Changed ˎˊ˗

- **Name and executable** — the app is `MediaSaver.exe` (was `ReelsSaver.exe`); the repository is
  `softoblivion/media-saver` (the old address redirects). The window title, settings sheet and logs use the new name.
- **Portable data folder (breaking)** — settings, history, cookies, logs, engines and updates now live in
  `media-saver_data\`
  next to `MediaSaver.exe`. Nothing of the app's state is written to `%LOCALAPPDATA%` any more. To keep your old settings and sign-in, copy `%LOCALAPPDATA%\ReelsSaver` to
  `<folder of MediaSaver.exe>\media-saver_data` once; otherwise the app starts fresh and downloads its engines again.
  The override variable is now `MEDIA_SAVER_HOME`.
- **Typography** — a new type scale with Inter (display and text) and Geist Mono (links, codes, versions);
  tabular figures for sizes, speeds and counters.
- **Status controls** — a quiet version label sits next to the engine chip; it opens the update panel, built like the engine popover.
- The link-cleaner error for a foreign host is `not_supported` (was `not_instagram`).
- Job history format is version 2 (older entries load as Instagram MP4 jobs).

### ⤷ Fixed ˎˊ˗

- Error messages of YouTube jobs no longer mention Instagram; sign-in is offered for Instagram jobs only.

### ⤷ Removed ˎˊ˗

- **Hover glow** — the light that followed the pointer over glass surfaces is gone; the specular rim and the gel
  press stay.
- Runtime data in `%LOCALAPPDATA%\ReelsSaver` and the `REELS_SAVER_HOME` variable (see Changed).
- The single `quality` setting (`max` / `1080` / `720`); replaced by the per-platform settings.
