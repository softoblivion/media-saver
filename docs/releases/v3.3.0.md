## ⪩ Media Saver v3.3.0 ⪨

Larger text and a taller title bar, so the window reads comfortably on a large monitor at 100 % display scaling.

---

### ⤷ Changed ˎˊ˗

- **Text size** — every text style is one step larger: body text 14 px instead of 13, labels and buttons 13.5,
  headings 17, meta lines 12.5, paths and versions 13. Weights and line spacing stay the same.
- **Title bar** — 52 px instead of 44: a larger app glyph, the app name in the heading size, a taller version
  pill and larger Settings, Minimize and Close buttons.
